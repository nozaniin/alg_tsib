# Описание работы
Реализована сортировка пузырьком с оптимизацией (флаг swapped). Алгоритм попарно сравнивает соседние элементы и меняет их местами при нарушении порядка. После каждого прохода наибольший элемент «всплывает» в конец. Если за проход не было обменов — сортировка завершается досрочно. Сложность: O(n²). Код изменяет исходный список (in-place).
